# AgriBrain: Project Master Documentation

## Project Overview

AgriBrain is an AI-driven Digital Twin platform designed for Indian agriculture. It allows users to drop a pin anywhere on a map of India to automatically retrieve spatial agro-climatic data, select soil profiles, input farm acreage, and run a Machine Learning inference engine. The system predicts the most suitable crops, estimates yield and revenue, calculates irrigation water demand, assesses multi-hazard risks, provides SHAP (SHapley Additive exPlanations) feature attribution, and generates a dynamic 5-stage cultivation timeline.

## Core Objectives

* Replace static, template-based farming dashboards with a deterministic, data-driven Digital Twin.
* Eliminate backend dependency for core UI rendering (handling 404s gracefully with frontend local processing).
* Provide high-fidelity localized recommendations using a 45-crop dataset (25 short-term, 20 long-term).
* Integrate a multi-modal AI Agronomist (Vision + Text) using Groq (Llama-3.1-8b and Llama-3.2-11b-Vision).

## Historical Context & Pivot

Initial iterations of the project relied heavily on an AI coding agent that generated "mock" data, fake `if/else` chatbot templates, stringified JSX props causing React runtime crashes, and rigid Next.js routing that resulted in persistent `404 Not Found` API errors. The project underwent a massive, multi-phase literal overwrite protocol to bypass agent hallucinations, culminating in a resilient, zero-mock, production-ready system.

# Technical Architecture

## System Architecture

```mermaid
graph TD
    Client[Next.js Frontend - Vercel]
    Client --> |Map Click / Drag| OpenStreetMap[OpenStreetMap Nominatim API]
    Client --> |REST API / JSON| Backend[FastAPI Backend - Render]
    
    subgraph Frontend [Vercel]
        MapUI[Leaflet MapUI Component]
        Simulator[Simulate Page Engine]
        Fallback[Local Fallback Engine]
        MapUI --> Simulator
        Simulator --> Fallback
    end

    subgraph Backend [Render]
        Router[Double-Mounted Routers]
        Spatial[spatial.py]
        Simulation[simulation.py]
        Chat[chat.py]
        Router --> Spatial
        Router --> Simulation
        Router --> Chat
    end

    Backend --> |Vision/Text Inference| Groq[Groq API - Llama 3]
    Backend --> |Live Weather| IndianAPI[Weather API]

```

## Data Flow & Components

* **Frontend (Vercel):** Built with Next.js and Tailwind CSS. Implements `react-leaflet` for spatial mapping. Contains a local deterministic ML inference engine mirroring the backend to prevent downtime.
* **Backend (Render):** FastAPI application with `spatial.py` (reverse geocoding & agro-climatic base-lining), `simulation.py` (crop scoring, SHAP, timeline generation), and `chat.py` (Groq multi-modal LLM routing).
* **APIs:** OpenStreetMap Nominatim (Reverse Geocoding), Groq (LLM).

# Module & Workflow Documentation

## 1. Map & Spatial Module (`MapUI.tsx` & `spatial.py`)

* **Functionality:** Interactive map allowing users to click or drag a pin. Updates coordinates instantly.
* **Frontend:** Uses `react-leaflet`. Next.js image bundling issues bypassed using a raw inline SVG for the map marker. Implements `useMapEvents` for clicks and `eventHandlers={dragend}` for pin dragging. `MapFlyTo` controls smooth camera panning.
* **Backend:** `lookup_spatial` uses Nominatim to get the district, then applies deterministic rules based on Indian latitudes/longitudes to assign an Agro-Climatic Zone (e.g., Coastal Lateritic, Northern Plains) and baseline NPK/pH/Weather data.

## 2. Digital Twin Simulator (`page.tsx` & `simulation.py`)

* **Trigger:** User confirms soil, enters acreage, selects crop duration, and clicks "Run".
* **Workflow:**
1. Reads coordinates, overridden What-If parameters (Rain, Temp, NPK, pH), and Farm Area.
2. Filters the 45-crop database by duration (Short-Term vs Long-Term).
3. Calculates absolute difference penalties between current environment and optimal crop conditions.
4. Generates a Suitability Score (0-100%).
5. Calculates SHAP feature attribution (positive/negative impact of Temp, Rain, pH, N).
6. Digital Twin Math: Total Yield = (Base Yield * Suitability) * Acres. Revenue = Yield * MSP. Water Demand = (Crop Water Requirement - Effective Rainfall) * Acres.
7. Groq LLM / Local Fallback generates a 5-stage agronomy timeline.



## 3. Expert Chatbot (`chat.py`)

* **Workflow:** Receives either a JSON payload (text) or Multipart Form-Data (image + text).
* **Routing:** If an image is present in base64, routes to `llama-3.2-11b-vision-preview` with plant-pathologist system prompt. If text-only, routes to `llama-3.3-70b-versatile` using the active farm context.

# AI Agent Prompt History & Instructions

## Historical Context & Agent Failures

The AI coding agents (Cursor/Windsurf) repeatedly failed by:

1. Attempting to merge code lazily, leaving legacy artifacts (`name 'lookup_spatial' is not defined`).
2. Corrupting React JSX syntax by wrapping props in quotes (`zoom="{5}"` instead of `zoom={5}`), causing fatal client-side crashes.
3. Generating fake response templates (`if "wheat" in user_input`) instead of utilizing API keys.

## Corrective Prompts Used

To bypass agent hallucinations, a **Strict Literal Overwrite Protocol** was utilized.

**Prompt Snippet (JSX Syntax Correction):**

> "CRITICAL REACT RUNTIME CRASH FIX: STRIP STRINGIFIED JSX PROPS. Previous generations corrupted the JSX syntax by placing quotes around curly braces... You MUST remove the quotes and replace it with: `<MapUI onPinDrop="{handlePinDrop}" pin="{pin}"/>`"

**Prompt Snippet (Backend API Fix):**

> "Mount under both `/api/v1` and `/api` to prevent 404 path mismatches. `app.include_router(spatial.router, prefix="/api/v1/spatial")`..."

# Database & Dataset Documentation

## Indian Soil Profiles Dataset

8 deterministic baseline profiles programmed into the fallback engine and backend logic:

1. Indo-Gangetic Alluvial (pH 7.1)
2. Deccan Black Cotton (pH 7.4)
3. Coastal Lateritic / Alluvial (pH 5.7)
4. Southern Red Loam (pH 6.4)
5. Arid Sandy / Calcareous (pH 7.9)
6. Mountain Forest / Podzolic (pH 6.0)
7. Deltaic Clay Loam (pH 6.6)
8. Saline / Alkaline Usar (pH 8.2)

## 45-Crop Machine Learning Dataset

Hardcoded dataset used for zero-latency inference and mapping.

* **Short-Term / Seasonal (25 crops):** Rice, Wheat, Maize, Blackgram, Mungbean, Chickpea, Pigeonpea, Groundnut, Soybean, Mustard, Sunflower, Cotton, Jute, Potato, Onion, Tomato, Chilli, Okra, Watermelon, Muskmelon, Ragi, Bajra, Jowar, Lentil, Cabbage.
* **Long-Term / Orchard (20 crops):** Coconut, Arecanut, Mango, Banana, Pomegranate, Coffee, Black Pepper, Cashew, Papaya, Guava, Grapes, Sweet Orange, Apple, Sugarcane, Turmeric, Ginger, Rubber, Cardamom, Sapota, Jackfruit.
* **Features per crop:** Optimal Temp, Rain, pH, N, Base Yield (Tonnes/Acre), MSP (₹/Tonne), Water Requirement (mm).
