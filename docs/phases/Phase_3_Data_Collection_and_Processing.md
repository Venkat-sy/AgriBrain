# Phase 3 – Data Collection, Preprocessing & EDA

## Objectives
1. **Acquire and integrate** all core datasets required by the AgriSim system:
   - **Rainfall** – district‑level monthly time‑series (1901‑2015).
   - **Soil** – spatial polygon data for each district with associated soil‑type percentages.
   - **Crop Production** – district‑level historic production with derived yield per hectare.
   - **Crop Recommendation** – feature‑rich synthetic dataset (already present) used for classification.
   - **Crop Economics** – input costs, market price, spacing, and revenue data for each crop.
2. **Pre‑process** each dataset to a clean, ML‑ready format:
   - Handle missing values, outliers, and duplicate records.
   - Engineer domain‑specific features (e.g., monsoon ratio, soil‑type dominance, economic profit metrics).
   - Scale numeric features and encode categorical variables.
3. **Perform exploratory data analysis (EDA)** that validates data quality and drives feature selection for Phase 4 models.

## Current Status (as of 23‑Sep‑2026)
- All five primary datasets are downloaded and stored under `datasets/`.
- The **rainfall** processing pipeline (`prepare_training_data.py` task 4) creates `training_data/rainfall_processed.csv` with engineered monsoon features.
